# v2.7.1 发布说明（2026-10-18）

**多选分享换位置 · 分享一个目的地**

v2.7.0 上线当天的一次小步快跑：多选模式下「分享」折叠在 ⋯ 里不容易被发现，
按方案 C 重排 —— 分享升到工具条、文字清单并进海报页。

## 变更

| 项 | 内容 |
|---|---|
| 多选工具条 | 最右一枚「删除」→「分享」，点一下直接进海报页（不弹菜单） |
| ⋯ 面板 | 收敛为：删除 / 全选 / 取消选择。删除仍先确认「移入回收站」 |
| 海报页 | 多选进来时底部多一枚「只发文字清单」，直接发纯文本，不出图 |
| 文字清单 | 不设 9 件上限（海报格子有画布边界，文本没有） |

设计依据：删除与分享都是两字按钮，**等宽对调，宽度零变化** ——
「已选 N 件 + 四枚两字按钮」在 360dp 上的上限原样成立。
app 里「分享」从此只有一个目的地：详情页、多选、统计页三个入口都汇到海报页，
图或文字进去再选。
