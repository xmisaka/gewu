# 格物 v1.2.1

**东西放在哪，你记得，它也记得。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除主动点「找封面」外不联网，可从「我的 → 数据通道」导出备份包。

## 本版更新（相对 1.2.0）

- **「我的物品」页加入滚动折叠头部** —— 向下翻列表时把统计概览、图例、分类筛选、排序行整段收起，
  固定头部从约 313dp 压到 **129dp**，小屏机型可视行数从 2.7 行提到 4.75 行；回到顶部或往回翻立刻放出。
- **「我的」页四组分组卡片补齐左右 17px 留白** —— 上一版只有「概览」和备份品牌卡有留白，看起来参差。
- **修掉头部卡在收起态的 bug** —— 上一版要求滚动位置精确回到 8dp 内才算「到顶」，
  fling 停在离顶几十 dp 处就会卡住且自己回不来。

### 一 ·「我的物品」页：滚动折叠头部

顶部那截固定内容（统计概览、正常 / 将到期 / 已过期图例、分类筛选、排序行）原本要占掉约 **313dp**。

- **向下翻列表** → 整段收起，只留页头 + 搜索框（约 **129dp**）
- **回到顶部** → 立刻整段放出来
- **往回翻** → 也立刻放出来

首屏打开时仍是完整头部 —— 没有为了列表多两行，就把「打开想看什么」砍掉。

| | 固定头部 | 列表可视（360×800dp 屏） |
|---|---|---|
| 滚动前 | 313dp | 399dp ≈ **4.5 行** |
| 滚动中 | 129dp | 583dp ≈ **6.5 行** |

小屏机型（640dp 高）差别更明显：**2.7 行 → 4.75 行**。

**修掉的问题**：上一版的判定是「只有滚动位置精确回到 8dp 内才算到顶」。实测 fling 停在离顶
几十 dp 处、或最后一帧采样跳过 0 时，头部会**卡在收起态且自己回不来**。本版改为以位置为主、
方向为辅的四级判定（回到顶部 ≤56dp 展开 / 往回翻 >24dp 展开 / ≥88dp 收起 / 56~88dp 滞回带
保持现状），并在松手时加一次 JS 侧确认兜底。

### 二 ·「我的」页：分组卡片补齐左右留白

「数据通道 / 整理 / 外观 / 关于」四组卡片原本贴着屏幕左右边缘，只有「概览」和备份品牌卡有留白，
看起来参差。本版四组统一补上左右 **17px** 留白，与设计方案一致。

### 三 · 其他

- 切换筛选条件或视图时列表会程序化回到顶部 —— 现在**同步把头部展开**
  （程序化滚动不触发滚动回调，上一版会因此滞留）
- 数据库结构未改动（仍是 schema v2），**覆盖安装不涉及迁移**
- 界面文案、权限、图标均无改动

## 安装

**方式一 · 手机上直接安装（推荐）**

1. 把 APK 传到手机（微信 / QQ 文件传输、数据线、网盘均可）
2. 在手机上点开这个文件
3. 系统提示「未知来源」时允许安装：
   设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你用来打开该文件的 App → 允许
4. 安装完成后桌面出现「格物」图标

**方式二 · 数据线 + adb**

```bash
adb install -r 格物-v1.2.1-arm64.apk
```

若报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`（之前用 Expo Go，或用了另一套签名装过同名应用），
先 `adb uninstall com.gewu.app` 再装。

> **注意：卸载会一并清掉应用内全部数据**（物品、照片）。需要保留的话先在「我的」里导出备份包，
> 装完再导入。**覆盖安装（不加 uninstall）则不受影响。**

<details>
<summary><b>覆盖升级须知</b>（为什么必须用同一把密钥签名）</summary>

安装包使用**自有签名密钥**（`android/app/gewu-release.keystore`）。以后发布新版本必须继续用
同一把密钥签名，否则手机无法覆盖安装，只能先卸载旧版 —— 而卸载会丢数据。

密钥与口令备份在工作区的 `gewu-签名密钥信息.txt`，**该文件不入库、不外发**。
仓库里只保留格式模板 `android/key.properties.example`。

</details>
