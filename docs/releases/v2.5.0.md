# 格物 v2.5.0

**东西放在哪，你记得，它也记得。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除你主动打开的能力外不联网，可从「我的 → 数据通道」导出备份包。

> **这一版做两件事：把 AI 的入口露出来，把购买的路换回爱发电。**
>
> **AI 那三个入口以前对没激活的人是「根本不存在」** —— 不是藏起来，是没渲染。
> 原因不在这一处：设置页对未激活档**整页锁着**，所以「AI 助手」总开关永远停在关；
> 而入口该不该露，判断恰好挂在那同一个开关上。两处单看都不算错，
> 叠起来就是「免费用户从头到尾没机会知道有这东西」，而且**不报任何错**。
> 现在总开关默认打开，它只剩一个含义：**你主动关掉，这一族入口才收起来。**
>
> **购买改走爱发电**：创作者认证通过后，下单会**自动把激活码发到订单里**，
> 不再需要「加微信 → 等人回复 → 手发一串码」这套流程。四处购买入口的主按钮统一换成
> 「去爱发电支持」，打开的是我的**创作者主页**；微信降为**备用与联系** ——
> 想直接找我的，二维码和微信号都还在。

## 这一版做了什么

### 一、AI 入口露出来了（这版最要紧的一条）

| | |
|---|---|
| **原来** | 免费档首页看不到麦克风、看不到问一问星标；录入页也没有语音与识物。**不是灰掉，是整族不渲染** |
| **为什么** | 入口的判据是「AI 助手总开关」，而开关默认是关的；要打开它得进设置页 —— 那页对未激活档**整页锁着**。于是免费用户永远打不开开关，判据恒为假 |
| **现在** | 入口照常摆在原处（首页搜索框右侧的麦克风与星标、录入页右上两枚、照片条的识物）。免费用户点下去，弹的是**门控浮层**：告诉你怎么解锁，而不是什么都不发生 |

顺带把总开关的含义收干净了：**它现在只有一个意思 —— 你有没有主动把它关掉。**
所以设置页那句说明也跟着改了；未激活档**关不掉**这一族入口（那是「先激活」的代价），
已激活档仍然可以一键收起。三处文案（AI 设置页、门控浮层、支持者权益）**一起**改的 ——
这类「改了行为没改说明」的偏差不报错，只让人照着旧说明做错事。

> **默认打开 ≠ 偷偷联网。** 真正拦住联网请求的是「有没有填 API Key」，而 Key 只能你自己填。
> 总开关从来没被用来拦请求（全工程 6 处消费点全是界面可见性与深链兜底），
> 它一直是个静音键，不是同意书。这一版只是把默认值摆正。

### 二、购买改走爱发电（下单自动发码）

- **四处入口**（门控浮层 / 权益页 `/pro` / 我的页 / 支持者页）主按钮统一成「去爱发电支持」，
  打开的是我的**创作者主页**，在里面的方案点进去下单，激活码自动进订单。
- **微信降为备用**：门控浮层与权益页仍并排留着「加我微信」次按钮，
  支持者页与我的页底部那张「联系我」二维码卡片照旧 —— 爱发电打不开、或者就想直接找我的人，路没断。
- 激活码那两句文案（`LICENSE_HOWTO` / `LICENSE_RECOVER`）也跟着换了口径：
  从「加我微信获取」变成「去爱发电主页下单，激活码自动发到订单里」；
  码丢了先回订单里重看，实在找不到再加微信。
- ★★ **落点为什么是主页、不是商品详情页**（当晚实测更正）：
  商品页 `/item/…` 对**未登录访客**直接给**登录墙** —— 从 App 点「去支持」的人里，
  没注册过爱发电的看到的不是商品、而是一张登录表单，**而这件事不报错**。
  于是把两个地址**合并成一条**：`AFDIAN_ITEM_URL` 删除，`AFDIAN_URL`（创作者主页）
  既是购买入口、也是平台认证的依据。
  合并而不是「两个都留、只换指向」的理由：两个常量并排躺着，
  下一个改代码的人就得重新判断「这次该用哪个」—— 而这个判断已经错过一次了。

### 三、支持者权益里补上「批量识图」

这三个字此前在权益文案里**一次都没出现过** —— 不是漏改，是从来没人写。
它其实是最省事的那一个（一次最多 9 张，逐张识别后在清单里核对、一次入库），
却没出现在任何一个「你付钱买到什么」的地方。现在三处一起补齐：

- **支持者功能说明**（`entitlement.ts`）：`proSide` 改成「拍照识物、批量识图、问一问、语音录入四个入口」，
  门控浮层的正文写明「一次能选最多 9 张」；
- **AI 功能说明**（`app/ai.tsx`）：页头副标题、未激活锁定态、总开关说明、语音那条注解，四处列举一起改成四个；
- **权益对比**（`app/pro.tsx`）：AI 那一行下面**摊开写成四个入口**，对比表明细卡同步。

功能本身**一行没动** —— 它一直都在，只是以前没人介绍它。

## 免费档一个字没动

配色主题、收纳、到期提醒、库存、照片、备份、桌面小组件、快捷方式 —— 全部照旧。
这一版三件事里，前两件是「让免费用户知道有什么」，第三件只是文案。

## 修订记录（同日晚间 · 同号换包 r1 → r2）

这一版在发布当天晚间**原地替换过一次包**（版本号仍是 **v2.5.0 / vc 30**，未升版）：

- **原因**：作者实测发现——商品详情页对未登录访客直接给**登录墙**，而这一版正是把按钮
  指过去的。点「去支持」的人里，没注册过爱发电的看到的不是商品、而是一张登录表单。
- **改动**：`AFDIAN_ITEM_URL` 删除，购买入口统一到 `AFDIAN_URL`（创作者主页）；
  四处入口与 `LICENSE_HOWTO` 的措辞跟着改。**功能逻辑一行没动**（一个 URL 常量 + 几处文案），
  无新权限、无新依赖、数据库结构未动。
- **为什么同号换包而不是升 v2.5.1**：对用户可见的部分只有「按钮打开哪个网址」，
  不值得推一次更新弹窗；而 v2.5.0 才发出几小时，重新下载即得。
  ★ **代价（已知且接受）**：已经装了 r1 的人**不会收到「有新版」提示** ——
  同号换包不触发版本比对（`isNewerVersion` 只比大小），他们要重新下载才拿到新链接。
- **归档**：r1（已发布过的那份）留在 `_build/baseline-v250-r1.apk`；
  新包归档为 `_build/baseline-v250-r2.apk`。两者都是下一版差分的基点。

## 已知的边界

- **未激活档关不掉 AI 入口。** 想把这族图标收起来，得先激活（设置页对他们整页锁着）。
  这是「让免费用户知道有这东西」的对价 —— 代价是那几枚图标会一直在，直到你激活。
- **AI 识图那一枚不在首页。** 它在录入页里（右上「批量识图」＋ 照片条的「识物」）。
  本版刻意**没有动图标位置**，改的只是「露不露」。
- **弹窗只写了 2 条。** 本版相对 v2.4.1 的用户可见改动就是这两件 ——
  但如果你手上是很早的版本（比如 v2.3.0）直接升上来，弹窗不会重述 v2.4.0 的
  「桌面小组件 / 备份到手机」那几条。完整的历史一直在官网页 `changelog.html` 上。
- **加微信那条路仍在，只是不再是主路。** 支持者页与门控浮层里那句话还写着
  「加我微信获取激活码」—— 它现在描述的是**备用**通道（爱发电打不开、或想直接找我），
  这一版没动它。
