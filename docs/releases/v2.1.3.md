# 格物 v2.1.3

**东西放在哪，你记得，它也记得。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除你主动打开的能力外不联网，可从「我的 → 数据通道」导出备份包。

> **这一版调整支持者档：价格定为 ¥36，统计洞察纳入会员。**
>
> ★ 这一版**刻意没有上官网的更新记录页**（它是权益口径的调整，不是新功能），
> 所以 `changelog.html` 上找不到它 —— 这份文档是仓库里的发布存档，补写于 v2.2.0 发版时。

## 这一版做了什么

### 支持者档调价：¥28 → ¥36

一次买断的价格定为 **¥36**。历史文档（v2.0.0 发布说明、roadmap、README）同步改成 36，
免得同一件事在几处写着不同的数字。

### 统计洞察纳入支持者档

「统计洞察」（总价值、日均持有成本、分类价值分布、柜子占用与近半年入库趋势）从这一版起
属于支持者功能：

- 加进门控表 `SUPPORTER_FEATURES.stats`；
- **`stats` 页面自身加守卫兜深链**（与 `ai.tsx` 同一个做法）—— 直接走链接进这一页也会被挡，
  不会出现「入口挡了、页面还能进」这种暗门；
- 「我的」页那一行**不藏起来**，未激活时点它弹门控浮层（复用既有的 `gateFeature`）——
  藏一行会让用户以为这个功能不存在。

> 免费档不受影响：素笺 / 靛青 / 青瓷三套主题、收纳、到期、库存、照片、备份恢复全部照旧。
