# v2.7.2 发布说明（2026-10-18）

**陈列修复 · 单件也是一整幅大图**

同日第三版。用户在真机上发现：单件物品选「陈列」模板，正文全空白
（只有标题、编号和落款）。

## 根因

陈列模板渲染的是 `model.cells`，而 `buildSinglePoster` 返回 `cells: []` ——
建模与模板过滤没对上。这与「一页账只吃统计」是同一类错误：
骨架要的字段在另一种内容形态下不存在，硬套出来就是一张只有标题的空海报。

## 修法（按用户意见：单件陈列就该显示这件物品的图）

- `buildSinglePoster` 填一格：`cells = [{ name, thumb: coverThumb, note: null }]`
- `gridColumns(1) = 1`：单件独占一行，**一整幅通栏大图 + 名称**（两列里孤零零一格反而失衡）
- `skinsFor` 撤掉临时加的「陈列只认多件」过滤——单件重新可用陈列
- 守门：`tests/share.test.mjs` 断言单件 `cells.length === 1`；
  `_build/mutate-share.py` M7「单件建模不填 cells」变异变红（7/7）
- 陈列列数三档：1 件一行 / 2–4 两列 / 5–9 三列
