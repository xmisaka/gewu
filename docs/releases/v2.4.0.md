# 格物 v2.4.0

**东西放在哪，你记得，它也记得。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除你主动打开的能力外不联网，可从「我的 → 数据通道」导出备份包。

> **这一版把「待办」搬到了桌面上。**
>
> 格物最有用的一屏其实是「待办」—— 快过期的、该补货的，都是**要在事情变糟之前看见**的东西。
> 可它藏在一个要三步才能走到的页面里：解锁、找图标、打开、切到待办。
> 而「想不起来看」恰恰是收纳这件事最常见的失败方式。
>
> 所以这一版加了一个 **4×2 的桌面小组件**，直接把那几行摆在你每天都会看到的地方。
> 它只做摘要，不做管理 —— 点一下卡片进 App，该改的在那里改。
>
> 顺带修好了一个从上线起就没成功过的按钮：「备份到手机文件夹」。

## 这一版做了什么

### 桌面小组件：待办看板（4×2）

| | |
|---|---|
| **放什么** | 「待办」页最上面那几行 —— 快过期的和该补货的，**去重后**按紧急度排 |
| **多大** | 默认 4×2；**可以长按拖动改高度**，最高 8 行、最低 1 行 |
| **点一下** | 进 App 的「待办」页 |
| **多久更新** | 数据或主题一变就重写；你每次离开 App 时都会同步一次 |

几个刻意的取舍：

- **它只做摘要，不做管理。** 卡片上不能划掉、不能改数量 —— 那是 App 里的事。
  桌面上最贵的资源是注意力，多给一个动作就多一分「算了我还是开 App 吧」。
- **不能上滑翻页。** 这是系统「小组件」的静态列表，不是可滚动的应用界面。
  显示不下的用页脚那句「还有 N 件」交代清楚 —— 想看全就把卡片拉高。
- **只允许改高度，不允许改宽度。** 卡片的全部价值在「能显示几条」，而条数只取决于高度；
  把它拉窄只会让页脚那半句话被截断，看着像排版坏了。
- **「还有 N 件」跟着实际显示了几条走。** 你把卡片拉高，这个数字会跟着变小 —— 它不会骗人。

### 长按 App 图标：三个快捷方式

| 快捷方式 | 到哪 |
|---|---|
| **录一件** | 直接进录入页，省掉「打开 App → 找到录入」两步 |
| **待办** | 直接进「待办」页（与点小组件卡片是同一个去处） |
| **找东西** | 直接进搜索，光标已经在输入框里 |

### 修复：「备份到手机文件夹」以前必定失败

`v2.3.0` 把「立即备份」从「弹分享面板」改成了「直接存进你挑的文件夹」，方向是对的 ——
但那个写入动作**从上线起就没有成功过一次**，每次都会弹一句「写入失败，请重试或改用「发送出去」」。

原因是它用错了系统文件接口的组合方式。这不是偶发故障，是**必现**的：
换一条路写成「先把文件名摆正、再整份拷进文件夹」之后就好了。

- 存入的文件名固定为 **`格物-备份.zip`**，那个文件夹里**始终只有最新的一份**（直接覆盖）。
- 历史归档仍留在 App 自己的缓存目录里，保留策略只在那里生效。
- 「发送备份包」那一行没变 —— 它才是真正「把包送出这台手机」的动作。

### 免费档一个字没动

配色主题（素笺 / 靛青 / 青瓷）、收纳、到期提醒、库存、照片 —— 全部照旧。
小组件、快捷方式、备份修复**都在免费档里**，这一版没有把任何东西挪进付费。

## 已知的边界

- **小组件是 Android 专属的。** iOS 那边对应的是 WidgetKit，实现路径完全不同，
  这一版先不给 iOS 用户一个装不出来的东西。
- **小组件不滚动、不交互。** 它是「摘要 + 一个入口」，不是把 App 搬到桌面上。
- **首次添加小组件时它可能显示「还没有数据」。** 那只是它还没拿到快照 ——
  打开一次格物，或者在桌面上点一下卡片，它就会填上。
- **刷新时机是「你离开 App 时」**，不是每秒轮询。刚在 App 里改完，回到桌面就能看到新的。
- **不要把小组件当成待办的唯一入口。** 它显示的是摘要，条数受高度限制；
  看全了还是进 App。
