# 格物 v2.4.1

**东西放在哪，你记得，它也记得。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除你主动打开的能力外不联网，可从「我的 → 数据通道」导出备份包。

> **这一版只修一件事：详情页的封面图不糊了。**
>
> 那张图以前取的是**缩略图**（宽 320 像素），而它占的位置有整屏那么宽 ——
> 在 3 倍屏上就是 1080 像素，等于把 320 撑到 1080，放大了 3.4 倍，当然发虚。
> 有意思的是**同一张照片点开全屏看是清晰的** —— 因为全屏那条路一直取的是原图。
> 所以这不是相机的问题、也不是照片的问题，就是详情页取错了文件。
>
> 现在它改用原图（长边 1600）。同一张照片，点开全屏有多清晰，详情页就有多清晰。

## 这一版做了什么

### 修复：详情页的封面图不再发虚

| | |
|---|---|
| **原来** | 详情页那张 230dp 的大图位取的是**缩略图**（宽 320 像素，另存一份给列表用的小图） |
| **为什么糊** | 那个位子是**整屏宽**：360dp 的手机 @3x 就是 **1080 物理像素**，320 → 1080 等于放大 **3.4 倍** |
| **现在** | 改取**原图**（长边 1600 像素）—— 与原图相符地缩下来，不是撑上去 |
| **看得见的差别** | 点开全屏有多清晰，详情页就有多清晰了；两处用的是同一份数据 |

顺带说明两件**没变**的事，免得引起误会：

- **列表、缩略条、编辑页的小图照旧用缩略图。** 那些位子最宽也就 300 像素，
  缩略图本来就够 —— 换成原图只会让滚动变卡、白费电量。
- **照片本身没有任何改动。** 原图与缩略图都还是老规格（长边 1600 / 宽 320，JPEG），
  库里的照片一张都没重压、没重存。这一版只是「详情页该看哪一份」的问题。

### 免费档一个字没动

配色主题、收纳、到期提醒、库存、照片、桌面小组件、快捷方式 —— 全部照旧。
这个修复在免费档里。

## 已知的边界

- **只在 3 倍屏上差别最明显。** 低分辨率设备上本来就取不到 1080 像素，
  这项修复在那里几乎看不出变化 —— 但它不会变差。
- **点开全屏仍然是最清楚的看照片方式。** 详情页现在是「够清晰」，
  要读型号、序列号那种小字，还是点开全屏。
- **老照片不用重加。** 这个修复是对**已有的**照片生效的 —— 库里的照片一直存着原图，
  只是以前详情页没去取它。所以你什么都不用做，升级后打开就清晰了。
