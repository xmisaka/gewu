# 格物 v2.7.0

**东西记得住，也拿得出手。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除你主动打开的能力外不联网，可从「我的 → 数据通道」导出备份包。

> **这一版只做一件事：让「发出去」这件事成立。**
>
> 前几版把柜子做清楚了 —— 记得住、找得到、算得出。但柜子一直是「自己看的」：
> 家人问「充电线在哪」，你得截一张带状态栏的图；想让别人看见你把日子收得多齐整，
> 屏幕上没有任何一个出口。
>
> **「做成海报」** 就是那个出口：选一件或几件，四套模板里挑一套，写一句（或不要），
> 出一张 1080 × 1350 的图，交给系统分享面板。**不上传、不生成链接、没有回传。**
>
> 顺手把多选那条工具条补上了「分享清单」—— 买菜这件事，图帮不上忙，文字才帮得上。

## 这一版做了什么

### 一、做成海报

三个入口，同一个页面：

| 从哪里进 | 出什么 |
|---|---|
| 物品详情页右上 | 一件东西的海报 |
| 首页多选 → 「⋯」→ 做成海报 | 最多九件，一件一格 |
| 统计洞察右上 | 一页账（件数、柜数、格位、近六个月曲线） |

**进来不是一排空白模板，而是一张已经画好的图。** 模板条在下面，点一下就换；
题语点一下就地改。理由很简单：多一步「先选模板」，就会少一半人 ——
而「素笺」「陈列」这些名字，不看自己的东西摆在里面的样子是没法判断的。

**四套模板，覆盖四种意图：**

- **素笺** —— 纯文字，一张纸一句话。没有照片的默认，也是整套里最安静的一套
- **陈列** —— 一件一格，最多九件。**超过九件不缩图**，直接说「最多 9 件，剩下的可以分两张」：
  缩成十二格就是一面缩略图墙，谁都不会看
- **一页账** —— 件数当主角，底下六根细柱是近六个月新增
- **暗房** —— 照片满幅，压一层深色渐变。**没有照片时它不出现**，不是让人选了才发现是黑的

**海报上那句话可以改，也可以不要。** 预设八句，分「认领 / 年岁 / 生活」三组。
留空就真的不显示 —— 逼着人写「文案」，最后多半是连整个功能一起弃用。

**两个只属于你的数字：**

- **编号**按**录入顺序**数，且**含回收站**。所以删掉一件，你那张海报上的编号不会往前窜 ——
  编号是个纪念性的东西，不能漂
- **陪了你多少天**：`2021.03 · 至今 1842 天`。到十年以上自动换成年，免得四位数把这行撑开

**为什么海报不跟七套主题。** 你换了皮肤，去年发出去的那张不该跟着变样，
否则「我的格物」不成为系列，只是一堆随机配色。四套模板的底色与字体是**固定的**，
只有一点品牌色点缀跟着当前皮肤走。这条与清册「纸上没有背光」是同一条判断。

### 二、多选加了「分享清单」

四枚工具条（分类 / 位置 / 标签 / 删除）**一个字都没动** —— 那条注释写着它们刚好占满 360dp，
多一个字就把「删除」挤出屏幕，而挤出去不报错。所以分享类动作收在「⋯」里：

| | |
|---|---|
| 做成海报 | 最多九件，出图 |
| 分享清单 | 纯文本，一行一件带位置，家人能直接复制、能加进购物车 |
| 全选 / 取消选择 | 顺手补上，多选里一直缺这两个 |

清单长这样：

```
厨房 · 调料架

· 老抽酱油（厨房 · 调料架，剩 3 件）
· 洗碗块（厨房 · 水槽下）

来自格物 · 收纳柜
```

标题按三条递降规则取：同一格 → 格名；同一柜 → 柜名；跨柜 → 「已选 N 件」。
**不做「取第一件的位置」** —— 那句会是错的，而且错得看不出来。

### 三、详情页顶栏换了排法

原来是「返回 / 编辑 / 删除」，现在是「返回 / 分享 / ⋯（编辑 · 复制为新物品 · 移入回收站）」。

不是四枚图标挤不下（这一页本来就没有标题），是语义：分享是「给别人看」，
删除是「毁掉它」，并排放在同一行里，一个手滑就是把东西删了。

## 技术记录

### 抓图这条路，以及为它加的一个模块

项目有过两次「能不加模块就不加」的裁决（二维码、清册的 PDF）。这次加了
`react-native-view-shot`，因为它是唯一能把「屏幕上的排版」变成「一张图」的路：

| 路线 | 结论 |
|---|---|
| `react-native-view-shot` | **选它**。导出 1080 × 1350 是在 canvas 上等比重绘，文字仍是矢量清晰 |
| `expo-print`（已在依赖里） | 出 PDF 不出 PNG —— 微信里是文件卡片，像发附件，不像分享 |
| Skia 直接 encode | 体积与学习成本对一次分享不成立 |

加之前核过包：它自带的 `AndroidManifest.xml` 是**空的**（不声明任何权限），
`build.gradle` 只依赖 React Native 本体。**autolinking 接上了，没有重跑 prebuild** ——
手写的 `android/` 与 Kotlin 小组件都还在。

## 已知的边界

- **只出图，不做「保存到相册」。** 这一版走系统分享面板：能发微信好友、发文件传输助手。
  **要直接发朋友圈，得先看分享面板里能不能「保存图片」** —— 部分机型有这一项。
  实测不行的话，是否为一个 `expo-media-library` 再换一次权限，留到下次决定。
- **海报的字体在安卓上可能落成黑体。** 项目用的是系统 `serif`，Android 基本没有中文字形，
  会回落到黑体。素笺在 iPhone 上是安静的宋体，在小米上就是一张黑体字条。
  要不要打包思源宋体子集（约 2 MB），等真机两侧对比过再定。
- **多件最多九件。** 不做「缩略图墙」：十二格那种图，发出去没人看。
- **没有水印短址，也没有二维码。** 落款只有「格物 · 收纳柜」四个字。
  海报是唯一一个用户愿意主动展示的位置，在上面放广告，代价不是难看，是用户从此不发了。
- **卡片（给家人看位置的那一支）没做。** 家人问「在哪」的场景已由「分享清单」覆盖；
  要图的那一半与海报共用同一套骨架，等有真实反馈再说。
