# 格物 v2.0.0

**东西放在哪，你记得，它也记得。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除你主动打开的能力外不联网，可从「我的 → 数据通道」导出备份包。

> **V2 这一版加的是「手」，不是「云」**：拍照识物、问一问、语音录入三件事，
> 全部建立在同一条底线上 —— **事实来自你本机，模型只负责把话说顺**。
> AI 默认关着、Key 由你自己申请、不填 Key 就等于这个功能不存在。

## 这一版有什么

### 一、AI 助手（支持者档）· 「我的 → 整理 → AI 助手」

四个能力，全部**默认关闭**：不填 Key、不开开关，就不存在任何联网链路。

**① 拍照识物，自动填表**
录入页照片区多了一个「识物」。拍一张包装，它带出名称、品牌、规格、分类与保质期，
你在保存前把把关就行 —— 三十秒的敲字变成三秒。

> 还没打开 AI 开关、或还没填 Key 时，点「识物」会**就在按钮下方**说清缺的是哪一步、去哪儿补。
> 这一条是照真机反馈改的：原先把提示放在表单最底部，而「识物」在页面顶部的照片区 ——
> 提示一直都在，只是没有人会滚到底去看见它，观感就是「点了没反应」。
>
> 用的两个模型都是免费档，限制是**同一时刻只允许一条请求**。所以连点两下会看到
> 「稍等十几秒再试」—— 那是模型侧的排队限制，不是额度用完了。识图本身慢一些，
> 等它的上限放宽到了 60 秒（弱网下光是把那张压缩副本传上去就要几十秒）。

**② 问一问：答案只来自你自己的库**
首页搜索框右侧多了一枚星标。问「家里还有什么能吃的」「这双鞋放在哪了」「哪件东西日均成本最高」，
它会先在本机把候选捞出来（按到期、按位置、按成本排序），再让模型把这些事实**改写成一句人话**，
下面挂着可以点开的物品卡片。

> 这是「接了本地库」与「通用聊天机器人」的分水岭：**事实全部来自本机检索，模型只负责措辞。**
> 模型就算胡说，底下那几张卡片也一眼能对得上。模型连不上时，本机那句话照样回答 ——
> **AI 挂了这个功能还在。**
>
> 早先这一屏的提示词**禁止模型点名物品**（怕它和下面的卡片重复），
> 结果它只能说「有几件快到期」——正确，但没用。现在允许它点名最相关的一两件：
> 「酸奶和牛奶这两天到期」比「有几件快到期」有用得多。反幻觉那几条一个字没松。

**③ 语音录入（不需 Key、也不能算 AI）**
说一句「厨房橱柜二放了包牛肉面，保质期到年底」，三行填好等你确认。
它走的是**手机自带的语音识别对话框**，录音发生在识别器里，所以格物不申请录音权限。

> **转写出来的那句话可以直接改。** 听错一个字不必重说整句 ——
> 「重说」要重走一遍系统识别框，还不一定比上次准。改完按「重新识别」重跑一次就行。
>
> **识别完给你的就是手动录入那张表**（名称、分类、位置、购买日期、价格、库存、
> 品牌、型号、标签、备注）—— 所以「语音能填哪些东西」与「手动能填哪些东西」
> 永远一致，不会再出现「价格说了也白说」这种事。
>
> 支持者档在这之后还会**自动**让模型再读一遍，补上本机规则没听出来的字段
> （只补空着的行，你填过的不会被改掉）。**它有没有参与、补了几项，界面上会照实说** ——
> 失败时也会说清是哪一步没成功，不会含糊过去。免费档没有这一步，但本机规则照常跑 ——
> 语音本身不因为 AI 而被加门槛。
>
> 部分机型的系统语音服务要先授权才能用（格物这边无法代你授权）。识别器报错时，
> 界面会给一句能照做的提示 —— 去系统设置里授权，或者改用手动录入，不再默默退回原样。

**④ 用量与花费，摆在明面上**
设置页有「本月用量」一行，写清识别了几次、问答了几次；用免费档时恒为 ¥0.00。

**⑤ 供应商可以自己换（不只是免费那一家），模型名也能改**
设置页里「供应商」那一行可以点开换：**智谱**（默认，有免费档）、**DeepSeek**、**Kimi**，
以及**自定义** —— 填任意 OpenAI 兼容端点，中转站、自建服务、别家模型都行。

免费档的代价是慢和排队（同一时刻只允许一条请求），想换快的、换便宜的、换更强的，随你。

**任何一家的模型名都能自己改**：「模型」那一段点「识图」或「问答」任意一行就能填，清空即回到预置值。
这不是给你添麻烦 —— 官方下线模型名是常事（DeepSeek 的 `deepseek-chat` / `deepseek-reasoner`
用了整整一年，2026 年 7 月被直接下线，请求当场失败），
自己能在文档里抄一个新名字填进来，就不必等 App 更新。

> **一条必须说清的：同一个服务商，不同模型的看图能力可能不一样。**
> 比如 DeepSeek：`deepseek-flash`（V4.1-Flash）能识图，
> 而 `deepseek-v4-pro` 在官方功能表里明确标着「Not supported」。
> 所以这两行是**分开填**的 —— 问答想用 Pro、识图仍走 flash，完全可以。
> 选到看不了图的模型时，识物入口会自动隐藏，不是坏了。

**必须说清楚的三件事：**

- **Key 是你自己的。** 到所选服务商的控制台注册领取，把 Key 粘进设置页就行。
  **格物不代出 Key、不中转、也不按量收费** —— 调用量记在你自己的账号上。
- **上传的只是压缩副本。** 识别时上传的图片压到长边 ≤1024px、JPEG 质量 0.8；原图与你的物品数据不出手机。
  **发给哪一家由你选的那一项决定**（含境外服务商），格物不参与、也不知道。
- **免费档一个功能都不少。** 录入、到期提醒、库存、照片、备份恢复全部照旧。AI 属于支持者档的是「入口」，不是「用量」。

### 二、支持者档 · ¥28 一次买断
不上架应用商店之后，这一版把「怎么支持我」和「支持了能得到什么」做成了闭环：

- **一次买断 ¥28**，含 V2 内全部支持者功能，不订阅、不自动续费。
- **激活码离线校验**：本机验证签名即可解锁 —— **不联网、不绑设备、不限台数**。
  换手机把同一串码再粘一次就行。
- 解锁内容：**AI 助手入口**、**朱砂 / 藕荷 / 胭脂三套主题皮肤**、**批量操作**。
- **素笺、靛青、青瓷三套免费** —— 免费档留三套是刻意的，不是随手定的数字：
  只给一套时，用户在「我到底能不能换个颜色」这件事上完全没有商量余地，
  而换肤不该是付费墙的第一道。这次补的**藕荷**（紫）与**胭脂**（玫红）就是往会员那边加的，
  它们与原有五套的色相全部错开（棕 27° / 青绿 172° / 蓝 215° / 红 5° / 紫 271° / 玫红 337°）。
- 选择器里**免费三套在前、会员三套在后**：前三个不带标、后三个带「支持者」标，分界一眼可见。
- 系统深色时的「玄夜」不参与门控 —— 锁住它等于让深色模式用户没有主题可用，
  那不是一个权益，是坏掉的功能。

### 三、检查更新（没有商店之后的唯一通知通道）

「我的 → 支持格物 → 检查更新」，冷启动时也会**每天最多查一次**。三条口径：

- 失败一律静默 —— 用户没问的时候不该看到任何网络相关的话；
- **不强制更新、不做倒计时**，「以后再说」只对那一个版本有效；
- 下载按钮指向**官网下载页**，而不是 APK 直链。

### 四、数量与库存（v1.5.0）

- 药品、耗材可以记「还有几瓶 / 还剩几包」，不再只能记「有」。
- 列表行尾多一枚只读胶囊，点开是快捷面板：**用掉一件 / 补一件**，带一次撤销机会。
- 「用完了」是一个派生态（数到 0 就是它），不会往库里写一个额外的状态。
- 留空即「只此一件」，老记录的行为完全不变。

### 五、v1.4.1 的修复

首页滑动时的卡顿与重影修掉了，统计条 / 图例 / 分类 chips / 排序这一整段
改成随滚动收起、回到顶部再放出，一屏能多看到好几条。

## 修复记录

装机后按真机反馈逐条修了下面这些，全都是「用户看得见」的问题
（轮数与条数不是一个体系，这里按条列）：

1. **点了没反应**（识物 / 语音）—— 提示一直存在，只是渲染在表单最底部，
   而触发它的按钮在页面顶部；语音则是引擎报错与「用户取消」在系统层同形，被静默吞掉。
2. **弱网下拍照识物必然失败** —— 上传副本要几十秒，超时被掐断后重试又撞上限流。
   放宽了超时、降了体积、并让 429 自动退避重试一次。
3. **分享二维码报错**（`expected scheme to be 'file', got 'null'`）——
   打包资源在 Android 生产包上取不到可用路径：RN 会把图重命名成 `res/g6.png`，
   `expo-asset` 按 hash 定位对不上。**图一直在包里**（按字节比对确认过），
   只是这条取件路径取不到它。改为把图（仅 1446 字节）直接内联进代码，落进缓存后分享。
4. **切换供应商后名字不变、自定义端点填不进去、模型名不能改** ——
   前两条是同一个根因：供应商状态放在模块级变量里，**改了不会通知界面重渲染**，
   于是「已经切过去了，这一行还是旧的」，而「接口地址」那一行也就一直不出现。
   改成 store 里的 React 状态（与换肤同一条教训：模块级变量不会通知界面）。
   第三条一并解决：模型名现在对**所有**供应商开放编辑，不再只有「自定义」能填。
5. **填输入框时被输入法盖住** —— 页面里的输入框没事，弹层里的会。
   根因：`adjustResize` 是设在 Activity 上的，而 RN 的 `Modal` 在 Android 上
   是一个**独立的 Dialog 窗口，不继承这个属性**。
   改成统一的弹层外壳（`SheetModal`）来听键盘事件、把弹层抬上去并压住高度上限 ——
   五个弹层原来各写一遍「Modal + 背板 + sheet」，于是这个 bug 也各写了一遍。
6. **没填完就测连接，换来一个「异常状态（400）」** ——
   自定义端点少了模型名时，请求体里的 `model` 是空串，服务端只能回 400。
   现在两头都拦：按钮在前置条件不满足时禁用并说清缺什么，
   网络层也在模型名为空时直接给一句能照着做的话，不把请求发出去。
7. **语音只能填名称 / 位置 / 到期三项** —— 说「5000 块」「昨天买的」「两瓶」
   全都白说，因为价格、购买日期、库存在这条链路上根本不存在。
   根因是一件事两套实现：识物一直走「回填手动录入那张表单」，语音却是自己一套。
   现在语音页也复用同一个表单，六项齐了；以后加字段也不用改三遍。
8. **AI 那一步失败时，界面在说谎** —— 无论成败都显示「已让 AI 读过一遍」。
   于是「模型没连上」和「本机规则没听懂」这两件完全不同的事，在用户眼里长得一样，
   只能得出「这么简单都识别不了」。改成照实汇报：未参与 / 进行中 /
   补上了 N 项 / 失败 + 原因。

## 隐私

- **数据默认不出手机。** 除「找封面」（联网搜图）与你主动打开的 AI 能力外，App 不发起网络请求。
- **AI 的三条边界**：默认关；只上传 ≤1024px 的压缩副本；事实全部来自本机检索。
- **没有云端、没有账号、没有统计 SDK。**
- 「关于」页与「AI 助手」页都把上面这几句写在明面上，不藏在说明里。
