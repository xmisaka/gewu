# v2.7.4 发布说明（2026-10-24）

**列表整行空白修复 · 多图可选封面**

一件是用户报的 bug（「明明有数据，列表却空了一行」），一件是他提的需求
（「多图能不能选某张当封面」）。后者其实早就支持，只是够不着 —— 所以真正补的是入口。

## 一 · 列表偶发整行空白

### 现象

用户两张截图：同一个「用完」筛选，统计说 2 件，列表只显示 1 件。
白卡的高度仍是**两行**，第一行的位置空着 —— 白底在、左右卡边在，**内容是空的**，
连行间那条发丝线都没有。

最后一条是判据：那根线是 `ItemRow` 自己画的 `borderBottom`。如果真是数据只查出
一条，卡片会缩成一行高；线跟着内容一起消失，说明**整个 `ItemRow` 子树被摘掉了，
而 cell 的外壳（`rowShell` 的白底与边框）还留着**。

### 根因

**Android 上 `FlatList` 的 `removeClippedSubviews` 默认是 `true`。**

`node_modules/react-native/Libraries/Lists/FlatList.js:162`：

```js
function removeClippedSubviewsOrDefault(removeClippedSubviews) {
  if (ReactNativeFeatureFlags.shouldUseRemoveClippedSubviewsAsDefaultOnIOS()) {
    return removeClippedSubviews ?? true;
  } else {
    return removeClippedSubviews ?? Platform.OS === 'android';   // ← Android 默认开
  }
}
```

裁剪动的是**原生子视图的挂载关系，不改布局** —— 于是「高度对、内容空」。
RN 自己在这个 prop 的类型注释里就写着
`Note: may have bugs (missing content) in some circumstances - use at your own risk.`

**为什么首页特别容易中**，两条叠着：

1. `ListHeaderComponent`（统计卡 + 图例 + 两排筛选 + 排序行）比列表视口还高，
   前几行长期在裁剪边界上进进出出；
2. 换库存档位 / 换筛选时会 `scrollToOffset(0)`，把 cell 整批推到视口外，
   紧接着数据又换了一批。

**旁证**：只有 `FlatList` 带这个 Android 默认值，`SectionList`（相册页）没有 ——
恰好只有首页列表报过这个症状。

### 修法

`src/app/(tabs)/index.tsx` 的 FlatList 显式 `removeClippedSubviews={false}`，
注释写清「别为了滚动性能改回 true」。

窗口化照旧生效（仍然只渲染可视区附近，`windowSize` 不变），关掉的只是
「已渲染的 cell 是否被回收」。库存上限 150 件、行高百余 dp，这点内存换可见性值得。

## 二 · 一件物品多张照片，选一张当封面

### 原来就有，但够不着

详情页点大图 → 进全屏查看器 → 底部「设为封面」。落库走 `promotePhoto()`
把那张的 `sort_order` 改成最小值，列表封面取 `MIN(sort_order)` ——
「换封面」和「把它提到第一张」本来就是同一件事，不需要新字段、不需要迁移。

问题是**要三步才够得着**，而人想换封面的时候正停在详情页看缩略条；
更要紧的是**缩略条上看不出哪张是封面**（只有「当前选中」有品牌色边框）。

### 改动

- **封面星标**：第一张左上角 14dp 圆点 + 8dp 星。与「当前选中」的 2dp 品牌色边框
  **分工** —— 星标说「哪张是封面」，边框说「正在看哪张」。以前只有边框，
  于是「封面」这个信息在界面上根本不存在。
- **长按任意缩略图换封面**（首张不接：它已经是封面，按下去什么都不变是最难判断的反馈）。
  与首页「长按进多选」同一套肌肉记忆，不新增按钮、不占版面。
- **缩略条下一行 11px 灰字**「长按缩略图可换封面」—— 长按是看不见的交互，
  星标只说得出「这是封面」、说不出「怎么换」。
- **`setCover` 顺手 `setActivePhoto(0)`**：照片重排后旧下标会指错人，
  大图位显示成另一张，用户只会觉得「我点错了」。
- 全屏查看器里的「设为封面」保留（放大看清型号再决定时仍走那条）。

### ★ 星标必须带白描边

棕褐色圆点压在深色封面上（黑壳产品、夜景照）会**整块融进去** —— 星标一消失，
「哪张是封面」就又没有线索了，而这正是这次改动唯一的视觉线索。

描边用 `Palette.pure`（七套主题下恒为 `#FFFFFF`），**不能用 `surface`** ——
后者在玄夜等深色主题下是深灰，等于在深色图上再描一条深色边。
