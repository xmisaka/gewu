# 格物 v2.2.0

**东西放在哪，你记得，它也记得。**

一套以「位置」为骨架、以「持有成本」为情绪回报的**纯本地**收纳记录工具 —— 物品分格管理、
到期提醒、照片记录。数据只在这台手机里，除你主动打开的能力外不联网，可从「我的 → 数据通道」导出备份包。

> **这一版补上「到期提醒」这个闭环：食品药品快到期时，手机会主动告诉你一声。**

## 这一版做了什么

### 到期提醒（本地通知）—— 这次的重点

在「我的 → 提醒」里打开。之后食品药品**快到期时，手机会主动提醒你一声**，
不用再自己惦记着去看那一页。

- **全程在本机**：不引服务器、不注册推送、不需要账号。排好的提醒由手机系统自己记着，
  格物没在运行也照样到点；关机重启之后也会自动接回来。
- **默认关闭**：打开它要弹系统的通知权限框，那是你的决定，格物不替你做。
  被拒了会自己落回关闭，并就地告诉你去哪打开。
- **提醒时刻** =（到期日 − 提前天数）当天上午 9:00。提前几天默认 3 天，
  也可以点「自定义」填 0~365 之间任意整数（填 0 就是到期当天）。
- **只提醒到期，不提醒补货**：「该补货了」没有时间轴，它继续留在「提醒」那一页和标签角标里。
- **点通知直接跳到那件物品**，包括从通知冷启动进 App 的情况。
- **「角标数字」开关**：关掉后底部「提醒」标签不再显示待办件数，点进去仍然看得到 ——
  它只是个显示开关，不是「取消提醒」。
- ★ 那一页还有一行 **「试发一条」**：点一下会发两条（一条立刻、一条二十秒后走系统闹钟），
  用来分辨「通知发不出来」还是「闹钟被手机按住」。**国产 ROM 的省电策略会把后者按住**，
  官网《问题排查》页写了各品牌的设置路径。

### 批量识图（支持者档）

录入页右上角（麦克风左边）的图层图标 → 一次选最多 9 张照片 → 逐张识别 →
在清单里核对名字/分类/位置 → 一次入库。

- 没读出字段的条目会留下照片并标「补个名字就能存」，可以单条重试；
- 要改全部字段就点「详细编辑」跳独立一页；
- 需要你自备一个**能看图**的模型 Key（BYOK，格物不代管），且当前是支持者档。

### 修复

- **从柜子详情新增录入后，返回回到那个柜子**（原来总是回到「我的物品」）。
- **新增时的位置默认值**现在优先取「你进来的那个柜子」，其次才是上次用过的位置。
- 录入页改成压栈打开，所以**它上面没有底部标签栏**，左上加了一枚返回键；底部五格的样子没变。

### 支持者那条线

- **购买入口打通**：爱发电商品页已上架，App 与官网都指向商品页；
  「我的 → 支持格物」、激活页、功能门控浮层三处都能直接去下单，**下单后自动收到激活码**。
- **微信二维码改成了名片式**：码上方写着作者昵称，点开的放大页里也有。
- **激活码说明精简统一**：获取（去爱发电购买，或加我微信获取激活码）与找回（加我微信重发一份）
  两套说法各归一处。

## 需要知道的几件事

- **通知是「安静」的**：不响铃、不震动、不弹横幅，只安静地落在通知栏里。
  想让它响，去 系统设置 → 应用 → 格物 → 通知 → 到期提醒，把重要度调高（这个旋钮归系统管）。
- **可能晚几分钟**：格物刻意没有申请「精确闹钟」这个特殊权限 —— 对「提前三天告诉我」
  这种事，晚半小时没有区别，不值得为它多要一个权限。所以 9:00 响成 9:08 是正常的。
- **已经过了提醒时刻的物品不会补发通知**：比如你下午才打开开关，而某件东西的提醒时刻是
  今天早上 9 点 —— 它不会立刻补一条，但它就在「提醒」那一页里。
- **包大了 1.32 MB**：`expo-notifications` 连带拖进 `firebase-messaging` 的代价。
  本地通知路径根本不碰 Firebase，但依赖在包里。
