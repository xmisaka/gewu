设计语言

配色、字级、组件三件套

整套界面只用一种底色、一种强调色。强调色控得很紧——它只出现在「可点的地方」和「要你看的地方」，其余全部交给层级与留白。三种状态色各自绑定一个语义，不做装饰性使用。

#8C5A34品牌主色主按钮、选中态、悬浮添加键
#F3E9DE品牌浅底品牌标签、成本卡、备份卡
#FBF9F6页面底色纸感米白，带一点暖
#2B241F主文字标题、名称、数字
#926521即将到期仅用于倒计时，不做其它用途
#5F7355在用 / 正常状态标签与安全提示

字体分两族：衬线管「叙述」，无衬线管「数据」。页面标题、App 名用衬线，条目名、字段值、数字全部用无衬线并开启等宽数字——金额和天数在列表里纵向对齐后，可信度会明显不一样。

设计取舍

五条贯穿全界面的决定

画的过程中撞到几个 PRD 里没定死的地方，这几条最终都落进了实现，也是这套界面看起来「像回事」的原因：

  1. 位置视图挂在「物品」页下，不占底部 Tab底部五个位置已经被「物品 / 相册 / 录入 / 提醒 / 我的」占满了，再塞一个位置 Tab 会让低频入口挤掉高频入口。改成首页右上角的「列表 / 位置」切换器，切换成本低、又不抢位置。
  2. 成本卡做成品牌浅底的独立卡片不跟普通字段行放在一起。它是整个 App 里唯一带情绪回报的信息，混在字段表里会被淹没。大面积品牌浅底全 App 只给两处：这张成本卡，和「我的」页的备份卡——都是「这件事很重要」的提示，用多了会廉价。
  3. 「保存并录下一件」视觉权重高于「保存并完成」主按钮给了「录下一件」，字号和面积都更大。这是刻意的：连续录入是 V1 成败的关键，界面要推着用户往前走，而不是引导他退出。
  4. V1 只有「过期时间」一个时间字段，没有保修源码里查不到任何「保修」相关字段或文案——这一版不做。留的口子是：将来真加「保修到期」，直接复用现在这套琥珀色倒计时样式即可，视觉层不用改。别把这两件事画成两个色，那会让「即将到期」这个信号失去唯一性。
  5. 缺失值统一显示「未设置」，且组合缺失时整行隐藏单个字段缺失显示浅灰「未设置」；但成本卡这类依赖多个字段的组合指标，任一缺失就整卡隐藏。绝不显示「¥0.00 / 天」——那会让人以为东西是白来的。
