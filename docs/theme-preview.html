四条准入规则

  1. 语义三色是红线。sage / amber / clay 永远锁在绿黄红三系，主题只许调明度，不许改色相 —— 用户靠色相分辨状态，品牌色一旦侵占语义区，状态提示就失效了。
  2. brand 只管「可点」与「需注意」，不承担状态含义。
  3. 对比度是准入条件，不是事后优化。正文 ≥ 10（远超 AAA），小字标签 ≥ 4.5。下面每张表都是当场算的。
  4. 深色不是浅色取反。卡片要比背景亮才浮得起来，分隔线要比背景亮才看得见，语义色要整体提亮。玄夜按深色逻辑单独配。
